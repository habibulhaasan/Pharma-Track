Under the Hood

PharmaTrack uses a modern Android technology stack engineered for stability, offline-first reliability, and clean code principles.

code

Kotlin & Jetpack Compose

Built entirely with Kotlin and Jetpack Compose for a declarative, reactive, and strictly typed UI that effortlessly scales across different device sizes.

cloud_sync

Firebase Firestore Sync

Utilizes Firebase Firestore with persistent local caching. This guarantees that operations continue seamlessly even when clinic internet connections fail.

schema

MVVM Architecture

Strict adherence to Model-View-ViewModel principles using Hilt for Dependency Injection, ensuring code remains decoupled, testable, and maintainable.
